## POC NextJs - Blog
### Installation

1. cloner le projet
2. dans un terminal, executer les commandes suivantes :
  - ```cd project```
  - ```make start```
3. acceder aux pages via les liens suivants :
  - [application blog (http://127.0.0.1:3000/)](http://127.0.0.1:3000/)
  - [Base de données (http://127.0.0.1:8080/)](http://127.0.0.1:8080/)
